Follow the setup in the [README](../README.md#setup).

## Try

Do these like a user would, then go beyond them: wrong input, cancel, undo, twice quickly, reload in the middle, two tabs. Tick them off as you go; add what you find on the way.

- [ ] Settings › AI: add an AI member (Claude Code, an API-key member), presets, permissions by role template, Safe mode, limits and budgets, the kill switch, the audit log. Bad key, missing CLI, a model that does not exist: every message must say what to fix.
- [ ] Where AI appears and what it does with AI off or no member: Ask AI dock (Ctrl/⌘+J), the chat docked in the ticket page, `@` mentions of an AI, `/ai` and the selection bar in editors, Draft with AI, Improve description, Split with AI, test cases from criteria, the daily digest, Docs AI (Ask the docs, page menu, Check this page, Write with AI, Draw a diagram, freshness, Docs health).
- [ ] One switch per project: turning AI off hides everything. Viewers can read but not ask.
- [ ] "What will be sent" and the cost shown before sending.
- [ ] Schedules: create once and repeating, "done when" checks, the Schedules tab (list and week), the marker on the ticket and on its card, edit, pause, delete, a time in the past, a time zone change.
- [ ] Runs (only if a model is available): live steps, asking back, approvals, stop at Review, stopping a run, a run limit, what an AI remembers, auto-compact.
