# AI v2: design TODO list

For the designer. Written 2026-11-07 on branch `claude/ai-team-architecture-7a1efc` (PR #316), from everything that changed since the merge base with `main` (`fcece3a9`: 70 commits, about 800 files, most of the v1 AI UI deleted), checked against the canvases `design/source/*.dc.html` (the source of truth; `design/screens/*.md` only as an index) and the code. Spec of the new solution: [`ai-v2.md`](ai-v2.md), plan and status: [`ai-v2-implementation.md`](ai-v2-implementation.md).

**Philosophy of v2** (it decides every verdict below): the board is only a monitor, a log and a ticket-management tool that supports the AI. It does not shackle the AI: no board-enforced workflow, no review gates, no approval locks, no hard tool allow-lists. A **team** (a lead plus roles, all Claude Code) does the work; the board shows it.

## How to read this

- **A. Design to update**: the code already changed, the canvas still shows v1. One table per canvas. Verdict **OBSOLETE** = delete the board from the canvas; **UPDATE** = keep and change what is listed; **VALID** = checked, still right (sample names may need a refresh).
- **B. Code with no design yet**: built in v2 without a canvas. For each: where it appears and the states to draw.
- **C. In design, missing in code**: not for the designer. It is the code TODO for the developer, with a recommendation (add / adapt / drop). Every "drop" means the matching canvas element is listed in A as "remove".
- Priority: **P1** = seen by every user or contradicts the product, **P2** = common, **P3** = rare or cosmetic.
- IDs are stable: `A-nnn`, `B-nn`, `C-nn`.

## The five most important items

1. **Review gate is gone** (A-026..A-028, A-032, A-149, A-146): AI summary with criteria claims, Approve → Done, Request changes, Take over, Undo run's changes, "Move blocked". The lead's markdown **Report** card replaces it (B-05).
2. **A member is a team** (A-049..A-056, A-004, A-142): lead plus roles, Claude Code only, Add an AI team dialog, role chips, role label on comments and steps (B-15, B-17). Every Antigravity / Codex / API-key sample goes.
3. **No mention intents** (A-010, A-176..A-178): "Ask / Do the work / Just notify" becomes the split button "Send to {team} ▾"; the running lead gets "Tell the lead now" (B-01).
4. **Run panel and run states as built** (A-018, A-019, A-022, B-04..B-10): "Stop run" (Cancel only while queued), no Pause or Open in terminal, steps without "of ~14", cost and tokens, role tags on steps, two-level run tree, instruction, report, question card, restart notice and Resources strip.
5. **Safety, approvals, workflows, Flow/Health/Story canvases are deleted wholesale** (A.10, A.13, A.14, A.15; whole-canvas deletes: AiSafetyCost, AiTeamReview, AiStoryFlow except the keep-awake chip, AiProviderConfig), and a new **Timeline** with lanes You / Lead / roles, role spans and hatched queued bars needs its canvas updated (A.8, B-13).

Also important for the developer: **C-01** (markdown shows as `**` in step titles, a real bug), **C-18** (the ticket's AI tab still runs on the `MOCK_AI_ACTIVITY` path and lacks the role tree, messages list and paused strips), **C-21** (Docs "AI edited this page · Undo" banner is missing).

## Corrections to the first assumptions

Some v1 things that look removed are **still in v2** and their canvases stay (partly):

- **Pause**: per-run Pause/Resume is gone, but **team Pause/Resume** (members list, team page, "N team paused" chip), **Pause all AI** (kill switch with "Cancel what is running now" / "Let them finish" and a reason), the top-bar label, the banner, the Resume dialog, card footers and the Timeline "AI paused" band are built. `AiPaused` is only partly obsolete (A.9).
- **Permissions**: no matrix, ceiling or approvals, but each team has a **Permission mode (Bypass / Auto)** and the project has a **Deny list** (Settings › AI › "How teams run").
- **Limits**: the team page and Settings › AI still have Runs at once, Runs a day, Tokens a day, Daily budget, Monthly cap, Per run, and **Memory of one run (MB)** (see C-12).
- **"Not metered"** is still printed when a run has no cost yet; once the CLI reports `total_cost_usd` and tokens, the run shows them (C-14).
- **State "Timed out"** is in the chips, but the v2 server never produces it (C-08).
- **Resources** is not a tab; it is a live strip on the run (event `ai.resources`) with a restart / stop notice.
- **Hooks for roles are gone**: roles are read from the CLI stream's task events. Nothing to draw, but the old "hook" step kind never shows.

## v2 words to use on every canvas

Team (not "AI member"), lead, role, Report, "Send to {team}", "Tell the lead now", "Leave a note for the lead", Stop run, Cancel run (queued only), Retry, Run again, Needs input, Started by "Run button by An Nguyen" / "Assigned by …" / "Ask by …" / "Scheduled", cost and tokens, step count without "of ~N", Permission mode (Bypass / Auto), Deny list, Pause all AI.
