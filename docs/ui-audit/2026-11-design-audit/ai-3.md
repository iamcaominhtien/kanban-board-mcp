- **Native `<select>` where the design draws a custom dropdown**, in at least 14 places: Run history filters, Suggested for a role, workflow editor (Who does it, Model, Effort), wizard (Add a role, Default workflow, Hand over by, The members run as), Board AI tier rows (18), rule editor (When, Trial first), Team on its own (Workflow, Triage, The PM, Done stays your move), Flow date range, Add AI member Model. Only TP-10 is filed as its own row.
- **`.ai-sub` regression from #283** (TP-1): hint paragraphs at 16px with inline bold broken onto its own line, in Settings › AI and the team wizard.
- **Role keys shown as names** ("Ba", "Qa", "Dev (TDD)" inside parentheses) on workflows, the ticket workflow and server messages (TP-8).
- **Pages drawn as modals**: the team wizard (TP-6), the Story page (SF-3) and the ticket workflow behind a tab (TP-11).
