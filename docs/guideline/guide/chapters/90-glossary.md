| Term | Meaning |
| --- | --- |
| **AI member** | A project member that is an AI. It can be assigned tickets and @mentioned. |
| **Backlog** | The first status of a ticket. |
| **Board AI** | The AI member that answers in the Ask AI dock and makes drafts. One per project. |
| **Ceiling** | The furthest status an AI member may move a ticket to. |
| **Criterion** | A one-line check on a ticket that says when it is done. |
| **Data folder** | The folder with the database and uploads ({ch:data}). |
| **Debug Space** | A journal of attempts on a ticket. |
| **Docs** | The per-project page tree. |
| **Idea Space** | Where ideas are captured and sorted before they become tickets. |
| **Inbox** | The first stage of an idea. |
| **MCP** | Model Context Protocol, the way agents use the board’s tools. |
| **Promote** | Turn an idea into a ticket. |
| **Run** | One piece of work an AI member does on a ticket. |
| **Safe mode** | AIs may only read and comment. |
| **Sketch** | The offline drawing editor. |
| **Workspace** | A scratch folder for a ticket or idea. |
