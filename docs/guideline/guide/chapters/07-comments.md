## Comments

Comments sit at the bottom of a ticket. They use the same editor as the description, and you can @mention a member. An @mention of an AI member asks you what you want: ask a question, ask it to do the work, or only notify it ({ch:ai-members}). Comments can be edited, deleted and restored.

## Attachments

Drag files onto the description or a comment, or paste an image. Files are stored in the uploads folder ({ch:data}), not inside the database. The Export in Settings includes them.

## One viewer for every file

Pictures, PDF, Markdown, text and code, HTML, JSON, tables, Office documents, audio and video, and archives open in one viewer, with the same keys everywhere. The viewer works offline.

- Use the arrows to go to the next file on the ticket.
- On a picture, **Draw on it** opens the Sketch tool ({ch:diagrams-sketch}).
- In the desktop app a file can be opened with the system’s own application or shown in Finder or Explorer.

!!! note "HTML files"
    HTML files are shown with scripts switched off.
