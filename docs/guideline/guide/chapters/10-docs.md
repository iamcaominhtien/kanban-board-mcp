Each project has a **Docs** space: a tree of pages written in a visual editor and stored as Markdown. Open it from the view switcher (++Mod+4++ in the desktop app).

## Create a page

1. In Docs, press **New page** (or {menu:File › New Doc Page} in the desktop app, ++Mod+Alt+N++).
2. Choose where it goes in the tree, give it a title and pick a template if you want one.
3. Write. The editor saves a **draft** as you type.
4. Press **Publish** (++Mod+Enter++) when the page is ready for others.

@figure docs-empty "A new Docs space: create the first page, import Markdown, or start from a template."

!!! note "Draft and published"
    A draft is yours until you publish. Search, Ask the docs and links only use published pages.

## The editor

The editor is visual and can switch to Markdown. Type `/` for blocks, `/draw` for a sketch, `/ai` for AI help. Keys:

| Key | What it does |
| --- | --- |
| ++Mod+S++ | Save the draft now |
| ++Mod+Enter++ | Publish |
| ++Mod+Shift+M++ | Switch between visual and Markdown |
| ++Mod+F++ | Find in this page |

## Versions

Every publish makes a version. Open **History** to see earlier versions, compare two of them as a diff, and restore one. A restore makes a new version; nothing is lost.

## Move, duplicate, delete

Drag pages in the tree, or use **Move to…**. **Duplicate** copies a page. Deleted pages go to the Recycle Bin, with deleted tickets, and can be restored.

## Who can edit

An admin sets who can edit pages in {menu:Settings › Docs}: **Everyone**, **Members** or **Admins**. People who cannot edit can ask for access.

@figure settings-docs "Settings › Docs."

## Search

Press the search button in Docs. The palette finds pages by title and text, with snippets and match counts, and offers **Create page** when nothing matches. Its **Ask** tab answers a question from published pages ({ch:board-ai}).

## Import and export

Import a Markdown file or a folder of them, in Docs or over MCP (`docs_write import`). Export a page from its menu. A sketch exports as a plain picture.
