AI provider configuration

The Configuration tab of an AI member (AI members, section D) is built from the member’s adapter: Claude Code, Antigravity, API agent, or Other MCP client. Each item is Documented (steps only) or Synced (stored on the board, written to the provider’s native files before each run). A board-level library shares items across members. Desktop only.
A
Configuration tab — overview and the adapter contract
The Configuration tab of an AI member profile is generated from its adapter. Each adapter declares which option groups it supports and in which mode; the UI renders only those groups, so a Claude Code member never sees an “agent loop” form and an API agent never sees “Hooks”. The matrix below is the contract.
