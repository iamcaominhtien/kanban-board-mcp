Note: "Testing" and "Review" are two new statuses, added between In Progress and Done — Status today is only backlog | todo | in-progress | done | wont_do. Intent: a ticket moves to Review once the code is up and ready for a look, then to Testing once review passes and its test cases are ready to run (pairs with the Test Cases tab), before Done. Board column set, column-count rollups and any other place that reads Status will need updating for dev to wire these in.
