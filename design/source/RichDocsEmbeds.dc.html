Embeds and attachments

What can be placed in a page besides text: an HTML embed that runs in a sandbox, video, draw.io drawings, code, files, the board’s sketches and canvases, page and ticket references, and links that become embeds. Each is shown on desktop and, where the layout changes, on a phone. Sample project: Kanban Board (KAN).

An HTML embed is a small web page that lives in its own box. It cannot see or touch anything else on the board.
Allowed
HTML and CSS

Blocked
Reading this board, your login or cookies
Network requests from scripts
Pop-ups and new windows
Sending you to another page
Camera, microphone and location

Rotating a token keeps the old one alive for a day, so integrations are not interrupted.

tokens.py
PythonCopy
1def rotate_token(user, old):
2 """Issue a new token and keep the old one for 24 hours."""
3 new = issue_token(user)
4 grace = timedelta(hours=24)
5 old.expires_at = now() + grace
6 audit("token.rotated", user=user.id)
7 # the old token still works until it expires
8 return new

The audit event is written before the new token is returned.
