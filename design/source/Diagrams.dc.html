G. Rules
Proposed. The main choice to confirm is where the editor runs.
Markdown & storage
  • In markdown a diagram is one line: ![Auth flow](diagram:dg_8f2a). The text of the page stays readable and diff-able.
  • Each diagram keeps its .drawio source plus an SVG preview made on save. The page shows the SVG, so it loads fast and prints.
  • The label becomes the alt text. A short text summary is offered so the flow is readable without the image.
  • Works wherever markdown renders: ticket description, comments, docs, acceptance criteria text.
Editor
  • draw.io opens in a full-screen layer inside the app. Saving returns the XML and the preview to the page.
  • Host choice: a self-hosted draw.io keeps drawings on your servers; the public editor sends the drawing to diagrams.net while open. Admin setting, default self-hosted.
  • Autosave a draft locally every few seconds; only Save to page changes the page.
  • Desktop and web. On phones diagrams are view, zoom and download only.
Permissions & history
  • Members can add and edit. Viewers can view and download.
  • Docs: each page version keeps the diagram version it used, so restoring a page restores its diagrams.
  • Tickets and comments: editing a comment diagram updates it in place and shows “edited”.
  • Deleting a diagram from the text only unlinks it. The file is kept in the Recycle Bin with the item.
