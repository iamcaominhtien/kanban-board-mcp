Hover cards and the peek panel
Hovering a chip shows what is there: a page’s first lines, a heading’s section, the block itself, or a ticket. Clicking opens the same thing in a side panel, scrolled to the target and marked, with its own back and forward. Touch has no hover, so a tap opens the panel straight away.

Rate limiting

Published · v15HMEdited by Hoa Mai · 2h ago

Overview

Every route counts requests per token in a sliding one-minute window. When a token goes over its limit the API answers 429 with a Retry-After header. See Auth for how tokens are issued.

Rate limits are not enforced yet. Tracked in KAN-12.

Auth
Tokens are scoped to a project and sent as a bearer header. A token can be rotated at any time; the old one keeps working for 24 hours so integrations are not interrupted.
Failed attempts are logged, never the token itself. See 📓Decision log for who may create one.

  • Rotation keeps the old token for 24 hours.
