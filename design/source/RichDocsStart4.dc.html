53. Import notes: Word — What a Word file brings in, and what it leaves out.
Import
Bring pages in from other tools
Markdown.md
Word.docx
HTML.html
Pastetext
Drop files here, or
Word files: .docx. Styles, tables and pictures come with the page; comments and tracked changes are left out.
What a Word file brings in
Kept: Headings, lists, tables, bold, italic and underline, links, pictures and footnotes.
Left out: Comments, tracked changes (the final text is kept), macros, headers and footers. Text boxes become plain paragraphs.
Nothing changes until you import.
54. Import notes: HTML — The same for an HTML file.
Import
Bring pages in from other tools
Markdown.md
Word.docx
HTML.html
Pastetext
Drop files here, or
HTML files: .html and .htm. Scripts are removed; styles are kept where the editor has a match.
What an HTML file brings in
Kept: Headings, lists, tables, links, pictures, and simple colour and alignment.
Left out: Scripts, forms, frames, style sheets and class names. An embedded video or frame becomes a link.
Nothing changes until you import.
What is left out, in short
Said where the file is chosen, not after the fact.
The page is converted once, on import; the original file is not kept in History.
A file over 20 MB is refused before it is read.
