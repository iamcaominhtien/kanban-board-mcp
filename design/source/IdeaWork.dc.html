Idea Space — research log, workspace & activity

Three tools from the ticket brought to ideas: a history of changes (Activity), a scratch folder on disk (Workspace), and a timeline of what was learned (a Research log in the spirit of Debug Space). Same icons, same layout, adapted to what an idea needs.
A. Three tools from the ticket, adapted for ideas
Tickets already have a history (Activity), a scratch folder (Workspace) and a work log (Debug Space), each opened from its own icon in the header. Ideas get the same three, in the same place and look, so people who know the ticket already know the idea. What changes is what they hold.

B. Research log: the story of exploring an idea
Replaces nothing; it is the idea’s version of the ticket’s Debug Space. A timeline of what was learned, tried and decided, with a kind on each entry, files, pinning, and links. Evidence (the tab) is the proof for one assumption; the log is the order things happened in. A finding can become evidence with one click.

E. States and edge cases

This idea is closedThe log, workspace and activity stay readable. Adding entries and files is turned off; reopening the idea turns them back on.
Viewer role
You can read, not writeOnly members can add to the log or put files in the workspace. Everyone who can see the idea can read the log and activity.

Delete a log entry
Delete this entry? Its attachments are removed too. It stays in Activity as “entry deleted”.

The log, workspace folder and activity move with it. The folder name does not change, so paths already pasted into comments keep working.

F. Rules
Proposed.
After promotion
  • The idea keeps its log and activity. The ticket’s “Started as an idea” block gets two links: Idea log (4) and Idea activity.
  • The workspace follows the choice made in the Promote dialog (move, copy, or leave).
  • Nothing is copied into the ticket’s own Debug Space or Activity; they start fresh, so a ticket’s history is only about the ticket.
Who and how
  • Anyone who can edit the idea can add log entries. You can edit or delete your own entry; owners can delete any.
  • AI members can add a Research or Finding entry when asked in the chat (“Save to log”), always with the AI badge, never as someone else.
  • The AI can write files only inside the idea’s workspace folder, only when you press Save. It never changes the repository from an idea.
  • Activity is automatic and cannot be edited.
Reuse
  • Same icon buttons, same panel layout, same filters and same file rows as on tickets, so there is one set of components to build.
  • The idea’s workspace uses the same root folder and the same retention settings as tickets (Settings › Storage), with a default of “while the idea is open”.
  • Log entries are markdown and use the same editor, with Sketch and Diagram available.
