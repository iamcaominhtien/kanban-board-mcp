Docs AI — ask, write, read and edit

AI inside the Docs space: an AI menu on every page, Ask the docs in the search palette, writing a page from a ticket, idea or notes, helpers for readers, and Docs-only actions in the editor. It uses the existing AI members, limits and audit, and never changes a published page.
A. What exists and what this board adds
Some Docs AI is already drawn, in the Board AI board (§G) and in the editor board (/ai). But the Docs boards themselves show none of it, it is limited to writing help, and it is off by default. This board puts AI into the Docs space as a whole. It uses the same AI members, permissions, budgets and audit log; nothing here is a new kind of AI. This board covers asking, writing, reading and the editor; the second Docs AI board covers keeping docs true, proposals, tickets and control.

Where AI shows up in Docs
  • The tree: Ask the docs (also Tab in the search palette) and Docs health with a count.
  • The page header: one AI menu, next to Comments and Share. It is the same button on every page.
  • The editor: /ai, the selection bar and Check this page.
  • Comments: @ an AI member in a thread.
  • The project top bar: Ask AI (the Board AI dock) stays as it is.
What the menu never does
  • Nothing here changes a page by itself. Summaries are shown above the page and are not part of it.
  • Everything that writes (Edit with AI, Check, Create tickets) opens a draft or a list to review first.
  • A person who cannot edit the page still sees Ask, Summarise, Check and Translate. Edit with AI and Create tickets are hidden for viewers.
When it is hidden
  • The whole menu disappears when Docs AI is off for the project. Nothing is greyed out and nothing says “upgrade”.
  • With no AI member that can read the project, the menu shows one row that opens AI members.
  • On a page marked Hide from AI the menu shows a lock and a one-line reason.
C. Ask the docs
Search finds pages; Ask answers a question using them. It lives inside the search palette people already know, so there is nothing new to find. Every answer shows its sources, and an honest “not covered” is a normal result, with a way to fix the gap.

How Ask works
  • In the Docs search palette, Tab switches between Search and Ask. Search stays the default; Ask is never run automatically.
  • It answers only from pages you can see, quotes the section it used, and says “the docs do not say” instead of guessing.
  • When pages disagree it shows both, with their dates. It does not pick a winner.
  • The footer says how many pages it read and how fresh the index is. A page you just published can take about a minute to show up.
  • Open as chat continues in the Board AI dock, with the same sources attached.
