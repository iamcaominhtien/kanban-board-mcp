Note: assembly, not new data — every piece here (sidebar, filter chips, column, ticket card) maps 1:1 to App.tsx/Board.tsx/Column.tsx/ProjectSidebar.tsx/FilterBar.tsx today, same props and state. Changes are all visual: (1) columns lose their flat neon background — a 3px color bar plus a colored count pill now carries the same at-a-glance identity, freeing every card inside to read the same way regardless of which column it's in (today's saturated fills wash out card contrast, worst on Backlog yellow and Done pink). (2) sidebar goes from the current light theme to the Ink Deep (#253D2C) surface from the system doc, project prefix badges and the board-toggle switch keep their exact current behavior. (3) search stays a text input, but priority and assignee move from chip rows to the Status-Menu-style dropdown (single list, checkmark on the active row) — three chip rows side by side read as noisy, one line of dropdown triggers doesn't. This adds a real filter too, not just restyling: a Type dropdown (All / Task / Bug / Feature / Chore, icon + label per row) — FilterBar.tsx only filters by priority and assignee today, so it needs an activeType state plus a t.type === activeType clause alongside the existing priority/assignee checks in App.tsx's filteredTickets; priority and assignee keep their exact current filtering logic, only the trigger UI changes. (4) the "blocked drag" confirmation keeps its current copy and both actions, restyled to the card/shadow language used for popovers elsewhere. (5) parent tickets keep the tinted-background-plus-indent treatment from Sub-task Grouping, now shown inside a real column. (6) two new columns, Review and Testing, sit between In Progress and Done — this is real, not just visual: Board.tsx's COLUMNS array needs the two new entries in this order (accent colors #6D5DD3 Review, #B4571F Testing, matching Status Menu's dots) and Status needs the two new values already noted on that board. Code review happens first, so the Review card shows who review was requested from; the Testing card shows its Test Cases roll-up inline (pass/running/pending dot, same wording as the header tooltip) since that's the whole point of the column. Recycle Bin, Members and Settings panels, plus List/Timeline views, are unchanged here — each gets its own screen when it's this one's turn.
