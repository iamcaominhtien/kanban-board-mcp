Feedback rules
Haptics. Light tick on long-press lift and on drop, success notification on Moved, warning on a blocked drop, error on a failed save.
Order. Inline banner for state that stays (offline, blocked). Toast for one-off results. Never both for the same event.
Loading. Skeletons for the first load of a lane, spinner in the button for saves, pull indicator for refresh.
Reduce Motion. Skeleton shimmer and drag tilt switch off; the lift keeps its shadow.
